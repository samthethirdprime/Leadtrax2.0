# URL Saver

A simple and lightweight web application for saving and managing URLs directly in your browser. This project demonstrates the use of JavaScript, the DOM, event handling, and Local Storage to create a persistent bookmark manager.

## ✨ Features

* Save URLs manually.
* Save the current browser tab with one click (when used as a Chrome extension).
* View all saved URLs instantly.
* Delete all saved URLs with a double-click confirmation.
* Automatically persists saved URLs using Local Storage.

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/url-saver.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

### Chrome Extension (Optional)

If using the extension version:

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the project folder.
5. Pin the extension and start saving tabs.
